# Комикс

Сохраните готовые страницы в эту папку: `page-01.webp`, `page-02.webp` и так далее. Поддерживаются WebP, PNG и JPEG. Затем укажите их по порядку в `site/comic.json`:

```json
{
  "title": "ДауренVerse · Глава первая",
  "pages": [
    { "src": "assets/comic/page-01.webp", "alt": "Обложка комикса о Даурене" },
    { "src": "assets/comic/page-02.webp", "alt": "Описание событий второй страницы" }
  ]
}
```

Пустой список показывает сообщение «История ещё рисуется». Просмотр появляется после загрузки обложки; следующая страница загружается заранее. Есть перелистывание, выбор страницы, увеличение и закрытие по Escape. Стрелки клавиатуры работают внутри просмотрщика. Для загрузки манифеста используйте локальный сервер или статический хостинг.
